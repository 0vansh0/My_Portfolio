# Vansh — Developer Portfolio

A modern, responsive portfolio built with React and Vite to showcase my projects, skills, education, and background.

## Live Site

[View the portfolio](https://my-portfolio-0vansh0.vercel.app)

## Features

- Responsive layout for desktop and mobile
- Introduction and about sections
- Selected projects with descriptions and links
- Skills and education sections
- Contact section
- Animated interactions and project details

## Featured Projects

### Cristal

A movie and TV discovery platform built with React and the TMDB API.

- [Live demo](https://cristal-movie-discovery-ewml.vercel.app/)

### Second Sale

A campus marketplace concept for students to buy, sell, and trade pre-owned books, electronics, and everyday essentials.

### Klyro

An AI-assisted code review and learning workspace. It helps developers analyze code, preview repair suggestions, test supported programs, and learn from common coding mistakes.

- [GitHub repository](https://github.com/0vansh0/klyro)
- [Live demo](https://klyro-pearl.vercel.app/)

### Green Cart

An AI-powered agri-commerce platform connecting farmers and buyers with market intelligence, transparent pricing, digital contracts, and logistics.

- [GitHub repository](https://github.com/0vansh0/GreenCart)

## Run Locally

### Requirements

- Node.js
- npm

### Setup

```bash
git clone https://github.com/0vansh0/My_Portfolio.git
cd My_Portfolio
npm install
npm run dev
```

Open the local URL printed in your terminal.

## Build

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
