# Vansh Raj — Developer Portfolio

A personal portfolio showcasing my projects, technical interests, education, and contact information. Built with React and Vite, with an interactive portrait experience and small project previews.

## About

I’m a developer and BS-MS student at IIT Patna, studying Artificial Intelligence and Cybersecurity. I’m interested in building thoughtful web experiences and practical software products, and I’m open to internship opportunities.

## Highlights

- Scroll-responsive portrait built from a sequence of multiple camera angles, with transparent cutout assets for a cleaner presentation.
- Mouse-reactive hero treatment and animated, responsive interface.
- Interactive skill filters and project mini demos.
- Project case studies describing each project’s challenge, approach, and next steps.
- Keyboard-accessible terminal widget with commands for exploring portfolio information.
- Education timeline and streamlined contact links.

## Run Locally

### Prerequisites

- Node.js (current LTS recommended)
- npm

### Install and start

```bash
git clone https://github.com/0vansh0/My_Portfolio.git
cd My_Portfolio
npm install
npm run dev
```

Vite will print a local URL in the terminal, usually `http://localhost:5173`.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server. |
| `npm run build` | Create a production build in `dist/`. |
| `npm run preview` | Preview the production build locally. |
| `npm run lint` | Run Oxlint on the project. |

## Deployment

The project can be deployed to static hosting that supports Vite builds, such as Vercel, Netlify, or GitHub Pages.

1. Import the GitHub repository into your hosting provider.
2. Set the build command to `npm run build`.
3. Set the output directory to `dist`.
4. Deploy. Configure SPA fallback to `index.html` if your hosting provider requires it.
